Function getAllDocuments

  • getAllDocuments(
        documentName: string,
        documentType: string,
        asUuid?: boolean,
        minOwnerRole?: DOCUMENT_OWNERSHIP_LEVELS,
        filterFields?: [string],
        predicateFunction: Function,
    ): Promise<[string | Document]>

    Search all documents in the game, including world and packs, according to the given constraints and return them in an array.

    Example usage:

    await ed4e.utils.getAllDocuments(
    "Item",
    SYSTEM_TYPES.Item.spell,
    false,
    ["system.level", "system.tier"],
    x => ( x.system.level > 3 ) && ( x.system.binding === true )
    )

    Parameters

    • documentName: string

      The type of document that is searched for. One of game.documentTypes keys.

    • documentType: string

      The subtype for the chosen document type. One of the appropriate game.documentTypes values.

    • asUuid: boolean = true

      If true, return the found documents as just their UUIDs. Otherwise, the full documents are returned.

    • minOwnerRole: DOCUMENT_OWNERSHIP_LEVELS = "OBSERVER"

      The minimal ownership role the current user needs to get any document.

    • filterFields: [string] = []

      An array of document property keys that are used in the predicate function. Must contain all used keys.

    • predicateFunction: Function

      A function that can be used for pre-filtering the searched documents. Must be a function that takes one parameter, either the document (for world documents) or index (for packs). It must return true if the item should be kept, or false for it to be discarded.

    Returns Promise<[string | Document]>

    A promise that resolves to an array of either Documents or UUID strings of the found documents. Empty if no documents are found.
