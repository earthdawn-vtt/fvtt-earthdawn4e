## Edit Mode

In the upper-left corner of the window, there is a small toggle button. You can use it to switch between Play and Edit mode.

This mode unlocks many editing functions or protects against accidental clicks and disruptive dialogs during play.

## Characteristics

At the top of the character sheet are the characteristics: defense, armor, movement, and health values. Most of these values cannot be changed directly by hand. Exceptions are damage values and the number of wounds. Those can be edited directly in their fields. All other values are calculated automatically. Characteristic values are based on calculations from the Player's Guide and depend on the character's attribute values.

To modify them, effects are required. Next to immutable values, you will find ➕ and ➖ icons beside the fields. These automatically create an effect (Active Effect) to adjust values temporarily. A normal click increases or decreases by 1. Shift+Click increases or decreases by 5.

## Navigation and Tabs

In the lower main section of the character sheet, there are several tabs. Click a tab name to open it.

Here is an overview of the tabs and what they contain.

### General

**Attributes:** Show the value, resulting step, and number of increases. Click the die icon to roll attribute, half-magic, or ability tests. In Play mode, the ➕ and ➖ icons are available again for temporary value changes. In Edit mode, an arrow is shown instead to trigger a permanent attribute increase.

**Resources:**

- **Recovery:** Maximum and current number of recovery tests, and recovery step. Various recovery actions can be triggered here.
- **Karma:** Maximum and current number of karma points, and karma step. The karma ritual can also be triggered here.
- **Devotion:** Maximum and current number of devotion points, and devotion point step.

Current resource values can be edited manually. Maximum and step can only be modified through effects.

### Abilities

This section describes options for talents, skills, and devotion powers. Every ability that has a test displays a die icon. You can roll the related step from there. Clicking an ability name opens a short description. Additional values such as action, attribute, step, rank, and strain are shown as well.

Each ability has buttons for increase, show in chat, edit, and delete. Some of these functions are only available in Edit mode.

#### Talents

In the Talents tab, talents can be shown by category or as one combined list (configurable in system settings). Knacks such as talent knacks, karma knacks, and special maneuvers are shown under their related talent.

#### Skills

In the Skills tab, skills can be grouped by categories such as Artisan Skills, Language Skills, General Skills, and Knowledge Skills.

### Spells

The "Spells" tab combines all spell-related information. Spells are grouped by circle by default, but can be shown in one ungrouped list in system settings. A dedicated navigator groups spells by schools (for example Elementalism, Illusionism) and provides a separate tab for matrices.

### Equipment

The "Equipment" tab lists everything a character owns, including gear, armor, shields, and weapons. Wealth and encumbrance are also shown. Encumbrance can be disabled in game settings.

### Legend

The "Legend" tab includes:

- Namegiver and a notes editor.
- Disciplines, paths, and questors with ranks and circles, plus the option to start advancement.
- The character's languages and the option to add additional languages.
- Legend point information (Total, Current, Spent) and a button to open legend point history.

### Links

The "Reputation" tab currently only contains the character's woven threads and their own true pattern. The personal pattern is only shown if it was added explicitly.

### Specials

The "Specials" tab is divided into three sections:

- **Status Effects:** Covers situational modifiers from the Player's Guide and creates temporary effects.
- **Temporary Effects:** Effects with a limited duration.
- **Permanent Effects:** Effects with the setting "Permanent".

Each effect is shown with an image, name, a checkbox (active/inactive), and a control menu. The control menu includes buttons for "Show in Chat", "Edit", and "Delete".
