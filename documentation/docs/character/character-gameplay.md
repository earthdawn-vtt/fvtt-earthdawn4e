<p>The following section describes the individual functions of the character sheet in detail.</p>
<p></p>
<div>
    <section style="overflow:hidden">
        <h3>Play and Edit Mode</h3>
        <div>
            <img style="float: right" src="../../../assets/manual/german/actor-sheet-edit-mode.png">
            <p>The already described Play and Edit mode enables or disables features in many places. This protects users from unintended changes and creates a clear separation that makes the character sheet easier to read.</p>
        </div>
    </section>
    <h3>Features in Play Mode</h3>
    <div>
        <p>In Play mode, various features are available in multiple places on the character sheet.</p>
        <h4>+/- Button</h4>
        <div>
            <p>The +/- buttons can increase or decrease values in many locations on the character sheet. Clicking edits a persistent effect (Active Effect) that stores all manual changes. Each additional click increases or decreases that effect.</p>
            <p>A normal click increases or decreases by 1, and Shift+Click increases or decreases by 5.</p>
            <p>Dice Button</p>
            <p>Many abilities and items can be used to trigger an action roll. Items that can trigger an action show a die icon instead of the image when you hover over them.</p>
            <img src="../../../assets/manual/german/actor-sheet-talent-tab-roll.png" alt="Dice Button to Trigger Action Roll">
            <h4>Blood Drop Button</h4>
            <p>Some abilities do not trigger an action roll but cause strain damage when used. Such abilities show a blood drop icon to trigger the action and apply damage.</p>
            <img src="../../../assets/manual/german/actor-sheet-talent-tab-strain.png" alt="Blood Drop Button to Trigger Strain Damage">
        </div>
        <h4>Spell Cards</h4>
        <div>
            <p>Spell cards provide two functions: attuning a spell and casting the spell itself.</p>
            <p>Attuning a spell opens a dedicated dialog where both quick attunement and full attunement can be performed.</p>
            <p>Casting also opens a dialog where additional options such as weaving threads or using raw magic can be selected.</p>
        </div>
        <p>Add to Favorites</p>
        <div>
            <p>On the right side of the character sheet, there is a "Favorites" area. Players can add frequently used abilities there. A context menu, opened by right-clicking an item, allows adding the following types to favorites:</p>
            <ul>
                <li>Talents</li>
                <li>Skills</li>
                <li>Devotion Powers</li>
                <li>Spells</li>
                <li>Powers</li>
                <li>Equipment (usable equipment only)</li>
            </ul>
            <img src="../../../assets/manual/german/actor-sheet-talent-tab-favorite.png" alt="Context Menu to add to Favorites">
            <p></p>
            <h4>Action Buttons</h4>
            <p>There are many action buttons that trigger specific actions. Here are some examples:</p>
            <h5>Favorites</h5>
            <div>
                <p>Favorites always trigger an action. Talents, skills, devotion powers, and equipment roll directly. Spells start by asking whether they should be cast through a matrix, a grimoire, or raw.</p>
            </div>
            <h5>Legend Point Overview</h5>
            <div>
                <p>The legend point overview opens a dialog showing all gained and spent legend points.</p>
            </div>
            <h5>Karma Ritual</h5>
            <div>
                <p>The karma ritual button is located to the right of the header. Activating it resets current karma points to maximum.</p>
            </div>
            <h5>Recovery</h5>
            <div>
                <p>The recovery icon (a small bed) next to the header opens a dialog to roll recovery tests or take a long rest.</p>
            </div>
            <h5>Initiative</h5>
            <div>
                <p>The initiative icon (crossed swords) next to the header rolls the current initiative step.</p>
            </div>
            <h5>Knockdown</h5>
            <div>
                <p>The knockdown button triggers a manual knockdown test.</p>
            </div>
            <h5>Stand Up</h5>
            <div>
                <p>The stand-up button triggers a stand-up test.</p>
            </div>
            <h5>Take Damage</h5>
            <div>
                <p>This button allows manually adding damage outside normal actions.</p>
            </div>
        </div>
        <h4>Add Effect</h4>
        <div>
            <p>Temporary and permanent effects include a "+" icon next to the header. Clicking it creates a new effect and adds it to the player character. A dialog opens to configure the effect.</p>
        </div>
        <h4>Situational Modifiers</h4>
        <div>
            <p>In the "Specials" tab, situational modifiers are shown next to effects. Activating a button adds a temporary effect. Activating it again removes that effect. Active buttons appear darker.</p>
            <p>The "Overwhelmed" effect is an exception because it can have multiple levels. Instead of a button, it uses an input field for the level.</p>
        </div>
        <h4>Equipment Status</h4>
        <div>
            <p>All equipment items can have different statuses (for example, "Owned", "Worn", "Equipped", "Off-Hand", "Two-Handed"). Clicking the status icon cycles to the next status.</p>
        </div>
    </div>
