The following section describes all features of the Earthdawn system for Foundry VTT.

## Basics

During development of the Earthdawn system, the focus was placed on Actors, Items, and Chat Messages. Tokens, Scenes, and similar elements were partly adapted but are not described in detail here.

### Actors

The Earthdawn system for Foundry VTT currently distinguishes nine different actor types:

- Character
- NPC (Non-Player Character)
- Creatures
- Spirits
- Dragons
- Demons
- Groups
- Traps
- Vehicles

#### Characters

Characters are the most important actor type and therefore provide the most features.

The following section describes each function available on a Character actor:

- Character Sheet — Earthdawn roleplaying functions for players
- Character Generation — Comprehensive character creation with multiple steps
- Legend Points — Managing and spending Legend Points to learn and improve abilities
